# CAD and Mechanical Source Files

Store editable CAD originals and manufacturing exports for the roller frame, brackets/supports, sensor mount, magnetic marker disc/pulley and electronics enclosure. Prefer source files alongside STL/STEP exports.

For each part and assembly, record units, measured dimensions, material, fasteners, manufacturing method, print orientation where relevant and assembly notes. Add roller spacing, shaft/bearing details, an assembly drawing and relevant fit tolerances. Prototype photographs are build records, not dimensioned engineering drawings.
